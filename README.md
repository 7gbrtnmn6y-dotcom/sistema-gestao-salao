# Sistema de Gestão para Salão de Beleza

Projeto Integrador – UNISA
Autora: Letícia Coutinho

## Sobre o projeto
Protótipo web para organização de um salão de beleza.

## Funcionalidades
- Cadastro de clientes
- Cadastro de serviços
- Agendamento de atendimentos
- Verificação de conflitos de horários
- Controle de estoque
- Registro de receitas e despesas
- Painel de gestão

## Como executar
1. Baixe os arquivos do repositório.
2. Abra o arquivo index.html em um navegador atualizado.
3. Cadastre um cliente e um serviço.
4. Faça um agendamento para testar o sistema.

## Tecnologias
HTML5, CSS3 e JavaScript.

## Observação
Este é um protótipo acadêmico. Os dados ficam armazenados localmente no navegador e não são compartilhados entre dispositivos.
